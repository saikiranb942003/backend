frontend : 
-> the frontend is the part of a web application or website that users interact with directly
it it is everything that we see and touch on a webpage
-> it includes :
-> Layout and structure of the page(where elements are present)
-> text, images, buttons, and navigation menus
-> animations, trasitions, responsiveness

Technologies used:
-> HTML : -> hyperText markup language - provides the structure/ content of the web page
-> Like the skeleton of a body

-> CSS (Cascading Style Sheets) – Adds styles (colors, fonts, layouts)
-> Like clothes or makeup for your skeleton.

-> JavaScript – Adds interactivity (clicking, animations, dynamic content).
-> Like giving the page a brain and movement

Popular Frontend Frameworks:
-> React.js (by Facebook)
-> Angular (by Google)

Frontend responsibilities :

-> Design and build UI/UX (User Interface/User Experience)
-> Make it responsive (works on mobile, tablet, etc.)
-> Ensure accessibility (usable by all users)
-> Optimize performance (fast load times)
-> Connect with backend APIs (to fetch or send data)

Backend :

-> the backend is the back side part of the web appliaction or server side  
-> It handles the logic, database interactions, authentication, and server ommunication

It includes :

-> Business logic (e.g., calculations, data processing)
-> Databases (where user info, posts,products, etc are stored)
-> APIs (used to connect the frontend and backend)
-> Servers (machines where the app lives and runs)
-> Security & authentication (logins, roles,data protection)

Technologies used :

-> python
-> Node.js 
-> Java 
-> PHP 

Frameworks :

-> Django (pyhon)
-> Flask (python)
-> Express (Node.js)

Databases :

-> Relational (SQL): MySQL, PostgreSQL, Oracle
-> Non-relational (NoSQL): MongoDB, Firebase, Redis

responsibilities : 

-> create and manage databases
-> write APIs to connect frontend and backend
-> Handle user authentication (login/signup)
-> perform data validation and security checks
-> optimize performance and scalability
