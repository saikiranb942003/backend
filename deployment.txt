 // deployment process (locally or on services like render, railway, heroku) 

// deployment 
-> deployment is the process of publishing our application to a live server 
so users can access it via the internet (eg: https://ourapp.onrender.com) 
-> for a node.js app this involves 
-> uploading our code to a cloud platform 
-> setting up environment variables (like db credentials, jwt secret) 
-> installing dependencies (npm install) 
-> running a build process 
-> starting our app with node or a process manager 

// deploying node.js app on render 
-> render is a cloud platform like heroku but with more flexibility and a generous free tier 
// pre-requisities 
-> a gitlab account with our node.js app pushed to a repo 
-> package.json file with start script 
-> .env file values ready    

// steps 
-> push our code to gitlab 
-> git init 
-> git add .
-> git commit -m "commit" 
-> git remote add origin https://github.com/yourusername/your-repo-name.git
-> git push -u origin main 

// create web service on render 
-> Go to https://dashboard.render.com 
-> click "new" > "web service" 
-> connect our gitlab account and chose our repo 

// configure the service 
-> name : our app name 
environment : node 
build command :
if we are using babel:
-> npm install 
-> npm run build 
// start command 
-> npm start 

// set environment variables 
-> click environment tab and add each variable from our .env file 


// click create web service 
-> render will :
-> clone our gitlab repo 
-> install dependencies  
-> build our app 
-> start our app on a public url like : 
https://yourapp.onrender.com
